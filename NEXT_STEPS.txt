🎯 สิ่งที่ต้องทำต่อ (4 ขั้นตอน):

1️⃣  ตั้งค่า SUPABASE (5 นาที)
    → ไปที่: https://supabase.com
    → สร้างโปรเจกต์ใหม่
    → Run ไฟล์: supabase-schema.sql
    → คัดลอก: Project URL และ Anon Key

2️⃣  แก้ไขไฟล์ app.js (1 นาที)
    → เปิดไฟล์: app.js
    → แก้บรรทัด 2-3:
       const SUPABASE_URL = 'ใส่ URL ของคุณ'
       const SUPABASE_ANON_KEY = 'ใส่ Key ของคุณ'

3️⃣  ทดสอบในเครื่อง (Optional)
    → เปิด Terminal ในโฟลเดอร์นี้
    → รันคำสั่ง:
       npm install
       npm run dev
    → เปิดเบราว์เซอร์: http://localhost:3000

4️⃣  DEPLOY ไปยัง VERCEL (3 นาที)
    
    วิธีที่ 1 - GitHub (แนะนำ):
    → git init
    → git add .
    → git commit -m "Initial commit"
    → git remote add origin https://github.com/USERNAME/skm-wellness.git
    → git push -u origin main
    → ไปที่: https://vercel.com/new
    → เลือก Repository → Deploy
    
    วิธีที่ 2 - Vercel CLI (รวดเร็ว):
    → npm i -g vercel
    → vercel login
    → vercel --prod
